# Studies in Light

An independent gallery layout demo by jackspiece, using four public domain paintings by Claude Monet.

[View the gallery](https://jackspiece.github.io/gallery-layout-example/)

The layout has an opening artwork, a staggered collection, readable captions, and an enlarged image view. It adapts to a narrow screen. The image links also work without JavaScript.

This demo was created as a work sample. Paintings: Claude Monet. Web design and code: jackspiece.

## Preview locally

No build step or package installation is required.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/` in a browser.

## Image sources

The files were obtained from Wikimedia Commons records marked as public domain. Titles and dates were cross-checked against source records. The image credits page has the source links, and `image-credits.json` records the download URLs, dimensions, dates and source-file fingerprints.

The page uses locally hosted WebP images, system fonts and vanilla JavaScript.

The MIT License covers the original site code. The artwork retains the public domain designation recorded at each source.
